## 1. Purpose

In a Python + TypeScript stack the **wire is where drift accumulates**. A renamed field or a changed
nullability breaks the frontend at runtime, in front of a customer, with no compile error. This
document fixes the conventions so the generated client is trustworthy.

## 2. Shape

```
React + TypeScript (Vite)   ──REST/JSON──▶   FastAPI
```

FastAPI holds **all** business logic: pricing, quoting, state machine, slots, queue, authorization,
payment orchestration, webhooks. The frontend renders and collects input. Node is build tooling only;
there is no Node server.

## 3. Route namespaces

| Prefix | Auth | Notes |
| --- | --- | --- |
| `/api/public/*` | none | Shop state, silhouettes, curated fabrics, policy copy. Generous per-IP rate limit. |
| `/api/me/*` | customer session | Profiles, saved configurations, orders, messages. **Never takes a `user_id`** — the session is the scope. |
| `/api/admin/*` | `require_admin` | Separate routes with their own unscoped queries and audit events. Never a flag on a customer route. |
| `/internal/sourcing/*` | service token | Scraper intake ([[17-sourcing-and-scraper-intake]]). |
| `/webhooks/stripe` | signature | [[13-payments-and-stripe]]. |

Order-scoped customer routes are nested — `/api/me/orders/{order_id}/…` — and always resolve through
`get_owned_order` ([[02-identity-and-authorization]]).

## 4. Request conventions

- Request bodies carry **ids and measurements only**, never money or state
  ([[03-security-baseline]] §2).
- Every model: `model_config = ConfigDict(extra="forbid")`.
- Ids are UUIDs in path params; no sequential integers on the wire.
- `PATCH` bodies use explicit per-route allowlist models. Never a generic partial-update model over
  the ORM object.

## 5. Response conventions

- Money as **integer cents or a decimal string** — matching the decision in
  [[01-data-model-and-migrations]] §4.1. Never a JSON float.
- Timestamps ISO-8601 UTC with an explicit offset.
- Enums are strings matching the Python enum values verbatim, so the generated TS union is usable
  directly ([[08-order-lifecycle-state-machine]] statuses, sub-stages, shop state).
- A price is **never** returned as a bare total — always the full `Breakdown`
  ([[04-pricing-engine]]) so the UI can render lines without recomputing anything.
- Errors: generic client-facing messages, machine-readable `code`, no stack traces
  ([[03-security-baseline]] §9). Absent and forbidden are both **404**.

## 6. Generated client

`openapi-typescript` consumes FastAPI's schema and emits types the React app imports. Regenerated by
an npm script; **CI fails if the committed output differs** ([[00-development-environment]] §7).

- [ ] **DECIDE:** types-only (`openapi-typescript` + a thin `fetch` wrapper) vs. a full generated
      client with methods (`openapi-fetch`, `orval`). Types-only is less magic and easier to debug;
      a generated client removes hand-written URL strings. Recommendation: **types-only plus
      `openapi-fetch`** — typed paths, no code generation of call sites.

Operation ids must be stable and explicit (`operation_id=` on every route), because they name the
generated symbols. A renamed function should not rename the frontend's API surface.

## 7. Versioning

v1 is a single-consumer API — the web app deploys with it. **No versioned URL prefix.** If the
scraper contract ever needs to change independently, `/internal/sourcing/*` gets its own version, not
the whole API.
